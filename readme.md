AutoRoomEQ Player is an Android audio player focused on high-quality playback, DSP correction, USB DAC use and network playback/control.

## What's new in Beta 0.3.0

### UPnP Renderer
AutoRoomEQ Player can now operate as a **UPnP network renderer**, allowing compatible UPnP control points to select the player as a playback target.

### HTML Remote Control
A new **browser-based HTML remote** allows the player to be controlled remotely from another device through a web browser on the local network.

### New headphone-correction engine
The **headphone correction engine has been reworked**, with improved handling of correction profiles.

Downloaded or calculated headphone correction curves can now be **edited directly in the app**, allowing users to customize the correction before playback.

### AutoRoomEQ Web 2.0 WAV import
The **RoomEQ** section can now load the correction **WAV file generated by AutoRoomEQ Web 2.0**, making it possible to use the calculated FIR room-correction filter directly in AutoRoomEQ Player.
