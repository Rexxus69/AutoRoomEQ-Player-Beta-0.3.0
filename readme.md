# AutoRoomEQ Player Beta

AutoRoomEQ Player is an Android beta audio player focused on high-quality playback, audio correction and real-device testing.

Main features:
- local music playback
- Bypass / Corrected playback modes
- USB DAC support with bit-perfect path detection where available
- headphone correction profiles and presets
- RoomEQ / FIR import from AutoRoomEQ
- web radio playback
- streaming search and playback
- stream download support where available
- music library scanning
- album art detection and display
- metadata display
- lyrics support
- playlist-style navigation
- support for common audio formats such as FLAC, WAV, MP3 and AAC
- updated Android UI for phone testing

The app is intended for testing on real Android devices with different DACs, headphones, music files, streams and radio stations.

Feedback is especially useful on USB DAC compatibility, bit-perfect status, Bypass/Corrected switching, RoomEQ/FIR import, streaming stability, downloads, album art, lyrics, crashes and format compatibility.

This is an early beta build, not a final public release. The APK is test-signed, so users may need to uninstall previous builds before installing this version.
